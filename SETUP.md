# Setup & Implementation Guide – Pokémon API Client

This guide explains how to install, configure, and run the Pokémon API Client so that you can reliably fetch Pokémon data and save it to a CSV file.

---

## 1. Prerequisites

Before you start, make sure you have:

- **Python 3.8+** installed  
- **Git** installed (optional, if cloning via Git)  
- An internet connection (the script calls the public PokéAPI)

To check your Python version:

```bash
python --version
